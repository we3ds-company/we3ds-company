## [1.0.0] — 2024

### Added
- `README.md` — WE3DS company profile with badges, tech stack, and service overview
- `Standards.md` — Repository structure, branch strategy, commit conventions, PR rules, CI/CD pipeline standards
- `Workflow.md` — End-to-end development workflow from issue to production deployment
- `Code-Quality.md` — Code review checklist covering architecture, security, performance, testing, and logging
- `Security.md` — Internal engineering security standards (secrets, auth, CORS, CSRF, rate limiting, file uploads)
- `Audit.md` — Repository audit checklist for assessing project health across 9 categories
- `frontend.md` — Frontend engineering standards: TypeScript, component architecture, state management, SEO, a11y
- `CONTRIBUTING.md` — Contribution guide covering branching, commits, PRs, reviews, and testing
- `SECURITY.md` — GitHub-standard vulnerability reporting policy
- `CODE_OF_CONDUCT.md` — Community code of conduct
- `LICENSE` — MIT License
- `.github/ISSUE_TEMPLATE/bug_report.md` — Structured bug report template
- `.github/ISSUE_TEMPLATE/feature_request.md` — Structured feature request template
- `.github/pull_request_template.md` — PR checklist template
- `.github/workflows/ci.yml` — GitHub Actions CI pipeline
- `.gitignore` — Standard git ignore rules

## 🔗 Quick Reference

### Starting a New Project?

1. Read [Standards.md](./Standards.md) — understand required structure and conventions
2. Follow [Workflow.md](./Workflow.md) — set up branches and CI correctly
3. Apply [Code-Quality.md](./Code-Quality.md) — review your code against the checklist
4. Apply [Security.md](./Security.md) — verify security before going live

### Reviewing a Pull Request?

→ Use the [Code Quality checklist](./Code-Quality.md#-code-review-checklist)
→ Use the [Security checklist](./Security.md#-security-checklist-pre-deployment)

### Auditing an Existing Repository?

→ Use the [Repository Audit Checklist](./Audit.md)
